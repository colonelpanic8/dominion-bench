# Key: Horton Fall 2019 Finals 4: Prince/Storeroom, Faithful Hound, Shepherd, Silos, Colonies

## Sources
- [Adam Horton, "Dominion: Fall 2019 Tournament Summary"](https://adamhorton.com/flog/dominion-fall-2019-tournament-summary/),
  tournament 2019-09-21. Horton designed and playtested this kingdom for the
  2-player finals bracket. [Kingdom sheet](https://docs.google.com/spreadsheets/d/1ViQF-GpoQYWCvz7H-Mr_4xKip7v59aUu_A2K9Z_nUd0).

## Expert summary
The intended deck has a Princed Storeroom and many Faithful Hounds:
Storeroom at the start of each turn discards cards for draw, and Hounds
discarded that way return to hand, so you start turns with a big hand. Add
Silos on top, and Shepherd (discarding Victory cards to draw) works reliably
as the main draw, with Courtier and Pillage as payload. City Gate and Haven
help get Prince and line it up with Storeroom. Horton opens
Ironworks/Storeroom, wants many Mills and Shepherds (a second Ironworks is
usually good), and gets Silos early to find Ironworks more. A few Havens and a
Market or two help reach $8 for Prince; meanwhile load up on Hounds. Once
Prince holds Storeroom, Courtier adds payload fast (Pasture has three types)
and playing Pillage every turn is a priority. Mill tricks: discard Coppers
with Mill and trigger a shuffle so the next hand is all Coppers, which blunts
Pillage and, with Silos, improves later draws. Don't take too long: Mills
empty fast and Estates are worth 2 VP with Pasture, so an opponent can end on
piles with competitive points.

## Rubric
- **R1** [core] (designer) Core engine: Prince on Storeroom plus many Faithful Hounds for big starting hands.
- **R2** [core] (designer) Shepherd is the main draw (Victory cards incl. Pasture/Estates discarded), enabled by big hands and Silos.
- **R3** [supporting] (designer) Opens Ironworks/Storeroom; adds Mills, Shepherds, a second Ironworks, and Silos early.
- **R4** [supporting] (designer) City Gate and Haven help find Prince and line it up with Storeroom.
- **R5** [supporting] (designer) Payload: Courtier (Pasture's three types) and a Pillage every turn.
- **R6** [supporting] (designer) Watches the clock: Mills empty fast, and Pasture makes Estates worth 2 VP, so a three-pile ending can come early.
- **R7** [supporting] (designer) Mill/Silos shuffle tricks (stacking Coppers into one hand) as a Pillage defense.

## Traps
- **T1** (designer) Building too slowly toward the Prince setup and letting the opponent pile out.
