# Key: Making Luck ep. 117, kingdom 5: Fisherman, Tiara, Baron, Develop, Stampede

## Sources
- [Making Luck ep. 117 "Rapid-Fire Kingdom Analysis 2"](https://www.youtube.com/watch?v=_6QemY1KJtc&t=2367s),
  2022-09-03, 39:40-47:35. Adam Horton and Wandering Winder, first look, no playtesting.

## Expert summary
There is no village, so the hosts look to the non-terminals (Fisherman,
Warehouse, Hireling) and want a deck of Fishermen, Warehouses, a Baron or
two, a Hireling, and Tiara with Gold. Trashing is weak, and they're
unimpressed by aiming for $6 for Hireling early. They disagree on the opening:

- One host likes Fisherman/Develop. Develop turns Estates into Silver or
  Warehouse, and turns a Fisherman into Tiara plus a topdecked Gold.
- The other floats Remodel/Stampede, aiming for Stampede on turn 2 with
  exactly $5 and remodelling Curses and Estates into Fishermen. Otherwise
  Fisherman/Baron (or Warehouse/Baron).

Tiara looks very good to both. Topdecking a Hireling bought with a
Gold/Tiara play and using Tiara to set up Fisherman's cost (topdecking it so
the discard pile stays empty) both came up. Ranger and Armory look awful,
Desperation is an endgame tool rather than an opener, and a Baron/Stampede
"golden deck" is too cute and slow.

## Rubric
- **R1** [core] (consensus) No villages, so the deck leans on non-terminals (Fisherman, Warehouse, Hireling) with few terminals.
- **R2** [core] (consensus) Tiara is very good here (e.g. Gold+Tiara to topdeck a Hireling; Tiara topdecking to keep Fisherman cheap). "Tiara, the more I think about it, seems very good here." (a host)
- **R3** [supporting] (consensus) Fisherman is a core card, and its cost depends on an empty discard pile, which other cards can set up.
- **R4** [supporting] (majority) Baron is a reasonable terminal in this deck (one host lukewarm).
- **R5** [supporting] (consensus) Desperation helps in the endgame (and to hit key prices), not as an opener.

## Traps
- **T1** (consensus) Ranger and Armory: "Ranger looks awful here, as does Armory." (a host)
- **T2** (consensus) A thin Baron + Golds + Stampede "golden deck": possible but too slow.

## Disagreements
- Opening: Fisherman/Develop (one host) vs Remodel/Stampede or Fisherman/Baron (the other).
- Baron: one host isn't warm on it; partly because Baron's Estate discard fills the discard pile, so Fisherman costs full price that turn.

## Grader notes
- Low-confidence key. Score mostly on R1-R2 and the traps; any of the
  discussed openings is acceptable if it's justified.
